# Blue photographic Altair panel

The runtime `panel.jpg` and `sprites.png` files in this directory are generated by `scripts/build_blue_panel.py` during CI/build preparation.

The base front-panel photograph is **MITS Altair 8800 Front Panel.jpg** by **Cromemco**, from Wikimedia Commons, licensed under **CC BY-SA 4.0**:

- Source: https://commons.wikimedia.org/wiki/File:MITS_Altair_8800_Front_Panel.jpg
- License: https://creativecommons.org/licenses/by-sa/4.0/
- Source SHA-1: `f496df0232032f7d0d46e9bbb306691b380d8c36`

RusTair resizes the photograph to 2048×869 for its front-panel coordinate system. Animated control sprites are generated procedurally by the build script rather than copied from the photograph. The generated panel derivative should be distributed under the same or a compatible CC BY-SA license.
